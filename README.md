# Ayan Sayyad — Portfolio

Personal portfolio website for Ayan Sayyad, an aspiring Data Engineer and B.Tech Information Technology student.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Sections

- Home
- About
- Skills
- Projects
- Experience
- Contact

## Run Locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

The portfolio will then be available on GitHub Pages.
